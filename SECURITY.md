# Security policy

Report a vulnerability by email to rahmat.wibowo21@gmail.com. Please do not open a public issue for it.
You will get an answer within 7 days. The site is static (no accounts, forms or database), so the realistic
risks are a compromised build or deploy pipeline, leaked secrets in the repository, and personal data in content.
Reports about content (corrections, removal) go through https://kawalkepakaran.org/kebijakan instead.
